# 深度 FAQ

1. **两个仓储为何同包同名？** 不同 artifact 提供替代轨道。
2. **能同时依赖两轨吗？** 易产生类冲突，除非项目有明确隔离。
3. **PO 字段怎样映射？** DomainModelHelper/DomainField 加默认约定。
4. **Query 能直接引用 PO getter 吗？** 用 persistence scope，领域 Query 不持有 PO。
5. **RepositoryRegistry 何时注册？** 仓储构造时按 M/Q 注册。
6. **原生查询为何有内存兜底？** 提供功能基线，不是生产大数据方案。
7. **租户信息从哪里来？** 当前适配器通过 ddd4j 上下文桥接。
8. **数据权限解析失败怎么办？** 当前实现记录警告；生产策略需决定 fail-open/fail-closed。
9. **自动填充覆盖哪些对象？** 以注解元数据与拦截器测试为准。
10. **必须测真实数据库吗？** 方言、事务、隔离和并发必须。
