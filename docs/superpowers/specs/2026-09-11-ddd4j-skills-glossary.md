## Style rules

1. Use present tense for capabilities: "This skill selects compatible versions…",
   not "This skill will select…".
2. Use second-person imperative for instructions: "Provide the JDK version",
   not "You should provide…".
3. Use `npx skills add full-stack-skills/ddd4j-skills --skill <name>` for every
   cross-skill reference — never `../<sibling>/SKILL.md`.
4. Keep tables, code blocks, and command snippets identical to the source.
5. Refresh the collection-date header in every translated reference file to
   `2026-09-11`.
6. Preserve the `✅ Strong At` / `⚠️ Needs Input` / `❌ Out of Scope` structure
   inside `## Capability Boundaries`.
